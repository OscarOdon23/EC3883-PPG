Se necesitan sensores de:
- PPG -> Mediciones de la densidad/volumen de la sangre en las venas a través
         de la reflexión de ondas electromagnéticas emitidas comunmente por un fotodiodo.
- Ritmo cardíaco -> Número de veces que se contrae el corazón en 1 minuto.
                    Se puede determinar de un PPG crudo.
- SPO2 -> Saturation of Peripheral Oxygen / Saturación de Oxígeno Periférico.
          Ni idea de que es. Se puede determinar de un PPG crudo.
- Variabilidad cardíaca --> Se puede determinar del ritmo cardíaco (según el profesor).

¿Que se necesita fundamentalmente?
- Algo que mida el PPG. No se puede hacer nada sin eso.

¿Qué es un Sensor Hub?
Básicamente es un microcontrolador que se encarga de manejar el sensor que mide los datos crudos y de calcular variables de interés automaticamente o por que se programa para ello.
Puede o no ser el mismo microcontrolador que se usa para transmitir los datos al "cliente".
Es útil si ya hace los calculos necesarios de fábrica ya que entonces el mcu que lo maneja solo tiene que pedirle los datos determinados y mandarlos a la aplicación que usa el cliente.

¿Donde va el Sensor Hub en la cadena circuital?
- MCU --- Sensor Hub --- Sensor

Sensores PPG:
- MAX30102 (Usa comunicación I2C)

Sensores Hub:
- MAX32664 (Usa comunicación I2C)

Circuito con Sensor Hub --> Hay que saber como programar al Sensor Hub para leer al Sensor
Circuito sin Sensor Hub --> Hay que implementar/usar rutinas de calculo existentes para calcular el resto de las variables requeridas a través de un PPG.

Microcontroladores:
- ESP32 C3 (Espressif)
- PIC32MZ W1 (Microchip)
^ Ambos tienen capacidades inalámbricas y puertos de comunicación I2C
